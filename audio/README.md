# Dramatized audio Bible

A full-cast audio Bible made with Fish Audio: every word of the text exactly
as printed, every speaking character a voice of their own, the same voice
wherever they speak. The KJV first; the procedure (`docs/SOP.md`) applies to
every translation we package.

| | |
|---|---|
| `docs/SOP.md` | the procedure, step by step, for any translation |
| `docs/fish-audio.md` | Fish Audio's API, as documented and as measured |
| `docs/casting.md` | how voices are chosen, and what productions and scripture taught us |
| `docs/decisions.md` | decisions made, and the ones waiting for the owner |
| `script/kjv/` | the KJV script: every verse split by speaker (generated) |
| `script/kjv/review.json` | verses a person should settle |
| `cast/principals.json` | hand-written voice briefs (125) |
| `cast/policy.json` | casting rules (letters, age, groups, accent) |
| `cast/cast.json` | the whole cast: 999 speakers, their briefs and lines (generated) |
| `lexicon/kjv.tsv` | pronunciations |
| `sources/sources.json` | every third-party file, pinned by SHA-256 |
| `THIRD-PARTY.md` | licences and credits for material that is not ours |
| `tools/export_phone.py` | tags the finished chapters as MP3s for a phone or Google Drive (`.cache/export/`) |

## Running it

Python 3.12+. Everything except the checks uses only the standard library.

```bash
cd audio
python -m abible sources fetch      # Glyssen and eBible files into .cache/
python -m abible script             # the KJV script, then review.json
python -m abible cast               # the cast list
python tests/test_script.py         # every verse rejoins exactly
```

Voices and audio need the Fish Audio key in `FISH_API_KEY` or in `audio/.env`
as `FISH_API_KEY=...` (never committed; the owner's other projects keep it in
`picture_ingest/.env`, which is also read).

```bash
python -m abible credit                     # Voice Design needs API credit
python -m abible voices top 125             # candidates for the principal cast
python -m abible voices audition "Moses" "God" "Jesus"
python -m abible voices choose "Moses" b0-c2.wav
python -m abible render RUT                 # .cache/out/kjv/RUT.1.mp3 + .json ...
```

The checks need faster-whisper and the speaker model, in their own
environment (they use the NVIDIA GPU):

```bash
uv venv --python 3.12 .cache/qa-venv
uv pip install --python .cache/qa-venv/Scripts/python.exe faster-whisper onnxruntime kaldi-native-fbank numpy huggingface_hub nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
.cache/qa-venv/Scripts/python.exe -m abible qa RUT
```

To delete the test voices made while measuring Fish's limits (private,
tagged `abible-test`):

```bash
python -c "from abible import fish; [fish._request('DELETE', '/model/' + m['_id']) for m in fish.my_voices() if 'abible-test' in m.get('tags', [])]"
```
